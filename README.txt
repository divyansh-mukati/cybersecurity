Cyber-Security Educational Sandbox
----------------------------------

Project Overview:
This project is a simple cyber-security learning environment created for educational purposes. It contains three modules:
1. File Integrity Checker
2. Network Monitor
3. Honeypot Simulation

Features:
- Detects unauthorized file changes using SHA-256 hashing.
- Displays active network connections and opened ports.
- Logs connection attempts on a fake port to simulate attacker probing.

Project Structure:
- /Sandbox : Contains all Python modules and main script.
- /Screenshots : Contains output screenshots of each module.
- /Recording : Contains video recordings (if any).
- Project file.pdf : Full project report in PDF format.
- README.md : Complete project description.

How to Run:
1. Install Python 3.
2. Install dependencies listed in requirements.txt using:
   pip install -r requirements.txt
3. Run main.py using:
   python main.py
